# 📚 Glossário Didático Universal

> **Dicionário Técnico e Conceitual do Projeto SENAI X História**

A tabela abaixo traduz em linguagem clara e acessível todos os termos de engenharia de software, conceitos web e padrões utilizados no projeto:

| Termo Técnico | O que significa na prática? | Onde é usado no Projeto? |
| :--- | :--- | :--- |
| **SPA (Single Page Application)** | Aplicação web carregada em uma única página HTML, onde as trocas de tela ocorrem via JavaScript sem recarregar o navegador do zero. | Toda a estrutura com [React 19 + React Router DOM](file:///home/desenvolvedores/programa/projeto-historia/package.json#L13-L16). |
| **Polling (Consulta Periódica)** | Técnica onde o código executa uma checagem repetida em intervalos curtos (ex: a cada 100ms) para verificar se novos dados surgiram. | Em [`BotaoCurtirTema.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/BotaoCurtirTema.jsx#L19-L36) e [`Rankings.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/pages/Rankings.jsx#L19-L27) para escutar o `localStorage`. |
| **LocalStorage** | Um banco de dados chave-valor leve embutido no próprio navegador do usuário, que não é apagado ao fechar a aba. | Armazenamento do array de `curtidas` e da escolha do `tema` (claro/escuro). |
| **MediaWiki REST API** | A interface oficial de comunicação da Wikipédia que permite buscar artigos, resumos e imagens programaticamente. | Em [`APIWikipedia.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/APIWikipedia.jsx#L17) consumindo `pt.wikipedia.org`. |
| **CORS (Cross-Origin Resource Sharing)** | Regra de segurança dos navegadores para controlar se um site pode pedir dados de outro domínio. | O parâmetro `&origin=*` na URL da Wikipédia permite que a aplicação consuma os dados sem ser bloqueada pelo navegador. |
| **encodeURIComponent** | Função nativa do JavaScript que transforma caracteres especiais (acentos, espaços, pontuação) em códigos seguros para URLs (ex: `Grande Depressão` vira `Grande%20Depress%C3%A3o`). | Em [`APIWikipedia.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/APIWikipedia.jsx#L12) ao sanitizar o título da pesquisa. |
| **HashLink (Navegação Suave)** | Componente que combina a troca de rota do React Router com rolagem animada até uma âncora específica da página. | Em [`Navbar.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/Navbar.jsx#L10-L11) navegando para `#conteudos` e `#producoes`. |
| **Parallax Scrolling** | Efeito visual onde a imagem de fundo se move em velocidade diferente ou fica fixa enquanto o conteúdo textual rola por cima, criando sensação 3D de profundidade. | Em [`Home.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/pages/Home.jsx#L17-L38) com a classe `.parallax1` e `.parallax2`. |
| **DOM Mutation (Mutação do DOM)** | Alteração direta na árvore de elementos HTML do navegador sem passar pela reconciliação virtual do React. | Em [`APIWikipedia.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/APIWikipedia.jsx#L46) com `wikiSection.innerHTML = info` e em [`BotaoTema.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/BotaoTema.jsx#L10) com `document.body.classList.add`. |
| **Spread Operator (`...`)** | Sintaxe do JavaScript (`...array`) que "despeja" todos os elementos de uma lista dentro de uma nova lista, garantindo imutabilidade. | Em [`BotaoCurtirTema.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/BotaoCurtirTema.jsx#L40) ao criar `[...arrayCurtidas, informacoes]`. |
| **Stale Closures** | Problema comum em React onde uma função assíncrona ou callback lê uma versão antiga e defasada de uma variável de estado. | Evitado no carrossel de [`Crisede1929.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/pages/Crisede1929.jsx#L50) usando o atualizador funcional `prev => ...`. |
| **Prop Drilling** | Padrão de passar propriedades de um componente pai para componentes filhos em múltiplos níveis. | Em [`Footer.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/Footer.jsx#L25) recebendo `corHeaderFooter` e `corInfoFooter` de cada página. |
| **Acordeão (Accordion UI)** | Padrão de interface onde uma seção se expande ou se recolhe verticalmente ao clicar em seu cabeçalho. | Em [`Footer.jsx`](file:///home/desenvolvedores/programa/projeto-historia/src/components/Footer.jsx#L36) com a classe `.aberto`. |
