# 📚 Glossário Didático Universal

> **Dicionário Técnico e Conceitual do Projeto Gratidão**

A tabela abaixo traduz em linguagem clara e acessível todos os termos de engenharia de software, banco de dados e desenvolvimento web utilizados no projeto:

| Termo Técnico | Significado Simples & Didático | Onde é usado no Projeto? |
| :--- | :--- | :--- |
| **MVC (Model-View-Controller)** | Padrão arquitetural que divide a aplicação em três camadas: o **Model** (que cuida do banco), o **View** (as telas HTML) e o **Controller** (o maestro que decide o que fazer com os dados). | Estrutura das pastas [`Backend/models`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/models/gratidaoModels.js), [`Backend/controllers`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/controllers/gratidaoController.js) e [`Frontend/Html`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/Html). |
| **TDS (Tabular Data Stream)** | Protocolo de comunicação binário proprietário usado pelo Microsoft SQL Server para transferir dados e comandos em alta velocidade. | Utilizado internamente pelo driver [`tedious`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/package.json#L15) em [`Backend/db.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/db.js). |
| **SQL Injection (Injeção de SQL)** | Uma das vulnerabilidades de segurança mais perigosas da web, onde um invasor digita comandos SQL maliciosos em um campo de texto para roubar ou apagar o banco. | Prevenido com [`request.addParameter()`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/models/gratidaoModels.js#L102-L103) no backend. |
| **NEWID()** | Função nativa do SQL Server que gera um identificador único de 128 bits (UUID). | Em [`ORDER BY NEWID()`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/models/gratidaoModels.js#L51) para sortear mensagens aleatórias de forma ultrarrápida. |
| **RESTful API** | Estilo de arquitetura de software que utiliza verbos HTTP (`GET` para buscar, `POST` para criar) e formato JSON para comunicação entre cliente e servidor. | Declarado em [`Backend/routes/gratidaoRoutes.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/routes/gratidaoRoutes.js). |
| **CORS (Cross-Origin Resource Sharing)** | Regra de segurança dos navegadores que bloqueia sites de domínios ou portas diferentes de conversarem entre si, a menos que o servidor dê permissão expressa. | Habilitado via [`app.use(cors())`](file:///home/desenvolvedores/programa/projeto-gratidao/Backend/index.js#L11). |
| **Operador Módulo (`%`)** | Operação matemática que calcula o resto da divisão entre dois números inteiros. | Em [`script.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/script.js#L23-L28) para fazer o slider de fotos rodar em loop infinito. |
| **Heurística** | Um atalho mental ou regra prática no código para resolver um problema rápido de forma eficiente. | Em [`histDeInspira.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/JavaScript/histDeInspira.js#L93) medindo se `stringURL.length <= 8` para distinguir fotos locais de links da internet. |
| **removeChild** | Método nativo do JavaScript que desanexa e destrói um elemento filho do DOM, liberando memória. | Em [`histDeInspira.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/JavaScript/histDeInspira.js#L57-L60) para limpar cartões antigos antes de uma nova busca. |
| **Parallax Scrolling** | Efeito visual de profundidade onde a imagem de fundo fica fixa enquanto o texto desliza sobre ela. | Em [`Frontend/Css/gratidao.css`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/Css/gratidao.css) com `background-attachment: fixed`. |
| **i18n (Internacionalização)** | Prática de projetar uma aplicação para que ela possa ser facilmente adaptada a diferentes idiomas e culturas. | Implementado nos botões de tradução em [`Frontend/script.js`](file:///home/desenvolvedores/programa/projeto-gratidao/Frontend/script.js#L56-L94). |
